## Status

Fresh start, 2026-07-26. `prds/` is empty; the first `product` pass over the strategy doc fills it. Phase 1 is the only phase that matters: ship one map to real strangers in Tel Aviv and find out whether anyone reopens it within a week.

## What replaced what

This workspace replaces `locali-brain`, frozen at `github.com/AviranGrisaro/locali` (branch `brain`). Carried forward: the strategy doc, the north star, the decision record, the lessons log, and the agent fleet. Everything else — 27 PRDs, 26 migrations, a 3,900-line worklog, a 130-entry process log — stays in the archive. `SALVAGE.md` explains how to reach it and what's worth reaching for.
